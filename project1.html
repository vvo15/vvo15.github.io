Quantify

This is the entire program for a website that displays your Spotify listening statistics. Current features include: display user profile picture, user profile name, artist name, artist album, and top tracks for 4 weeks, 6 months, and the past year. Made in collaboration with jpaul.

GitHub

Overview

Quantify is an open-sourced project that lets users run a program to see which songs, artists, and genres they play the most across different time ranges. The goal is to provide a free, editable alternative to subscription-based Spotify stats tools, so users can customize or learn from the code. This project was made in collaboration with my former teacher, one whom I now call my mentor, Jadorian Paul in order to gain experience in web application development. This project taught me how to effectively use APIs, GitBash, Node.Js, and GitHub. I was able to gain early experience in JavaScript, React, and CSS. This project was inspired by a problem and finding a solution to the problem: paid programs. As an avid music listener, I am also curious on my listening statistics, and after seeing most websites requiring a subscription for in-depth use, I decided to tackle on the problem to provide, others with the same problem, a solution.
